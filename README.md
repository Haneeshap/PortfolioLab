# PortfolioLab

PortfolioLab is a full-stack simulated fintech portfolio management application built for practical software engineering education.

## Objectives

- Build and test portfolio management features.
- Implement backend APIs and PostgreSQL persistence.
- Explore real-time updates using WebSockets.
- Develop a responsive frontend using Next.js.
- Introduce AI-powered portfolio analysis in a later phase.
- Practice Git, automated testing, and containerization.

## Planned Technology Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Real-time Communication:** WebSockets
- **AI Service (Future):** Python, FastAPI
- **Development Tools:** Git, GitHub, Docker

## Project Status

Milestone 0 — Environment setup and repository initialization.

## Disclaimer

PortfolioLab is an educational simulation. It uses fictional financial data and does not support real-money transactions or provide financial advice.
